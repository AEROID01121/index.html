# 🎯 Battleground Generator - PUBG Style Number Generator

Sebuah aplikasi web generator angka bergaya battleground dengan tema PUBG. Dilengkapi efek animasi peluru, asap, suara ledakan, karakter seksi, serta pilihan pasaran untuk simulasi angka.

## 🛠️ Fitur

- 🎮 Tema visual PUBG lengkap dengan M416, peluru jatuh, dan efek asap
- 🧨 Animasi saat klik generate (ledakan, peluru, asap)
- 🔁 Sistem refresh otomatis setiap kali pasaran diganti
- 📋 Riwayat angka 5 nama pemain dengan angka acak 4 digit
- ⚙️ Menu dropdown pasaran: SYDNEY LOTTO, CHINA, JAPAN, SINGAPORE, TAIWAN, CAIRO 1, CAIRO 2
- ⏳ Animasi loading 1% - 100% dengan M416 saat memilih pasaran
- 🧱 Layout kotak stylish & responsif
